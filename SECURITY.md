# Security Policy

## Supported Versions

The following versions of Ozentime AV are currently maintained with security updates:

| Version  | Support Status | Notes                                                                 |
| -------- | -------------- | --------------------------------------------------------------------- |
| 2.0      | ✅ Supported   | Fully self‑updating with AI redefinitions, rollback engine, VPN, and enterprise readiness. |
| 1.5 Pro  | ✅ Supported   | Self‑updating with AI engine improvements, but lacks rollback engine and VPN. |
| 1.5      | ❌ Limited     | Cannot update itself. Static definitions only. Users must manually upgrade to 1.5 Pro or 2.0. |

## Important Notice

- **1.5** is considered a legacy product. It does not have an updater module and cannot receive new definitions automatically.  
- **1.5 Pro** and **2.0** include self‑updating engines, so they continue to evolve with new definitions and behavioral improvements.  
- We recommend upgrading to **2.0** for full enterprise‑grade protection.

## Reporting a Vulnerability

If you discover a vulnerability in Ozentime AV:

- **Report via email:** ozentimeozen@gmail.com  
- **Acknowledgement:** Within 48 hours.  
- **Progress updates:** Weekly until resolution.  
- **Outcome:**  
  - If accepted, we’ll patch and update the next version.  
  - If declined, we’ll explain why and provide guidance and also proof the patch or fault is false.  

Please include detailed information (steps to reproduce, affected version, potential impact). Responsible disclosure helps us improve faster and keep users safe.
!Please don't download ozentime av from any other website and also don't trust information from unofficial sources except legit ones.

## Responsible Disclosure Guidelines

- Do not publicly share exploits until a patch is released.  
- Coordinate directly with us to ensure fixes are deployed safely.  
- Avoid actions that could harm users or compromise systems.
